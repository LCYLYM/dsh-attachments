# 自问式产品审查：决策与验收记录

这是采用 grillme 式追问方式整理的**可审阅产品决策摘要**，不是外部 agent 执行记录。问题围绕用户任务、失败成本与能否验证；没有让用户补答，也没有把个人思考过程当成产品文档。

| 追问 | 本版决策 | 怎么验证／还欠什么 |
| --- | --- | --- |
| 官方已经能传文件，为什么还装？ | 做目标明确的文件夹工作流，不以“支持文件”自夸 | 竞品资料；对话与侧栏各自流程测试 |
| 拖到侧栏，用户到底想要副本还是原目录？ | 明写“导入副本”；另设“使用主机原目录” | UI 测试检查两个入口，真实 FS 检查复制和不复制 |
| 浏览器给不了绝对路径怎么办？ | 不猜同名、不整盘找；手工确认主机路径 | 原目录注册测试；Finder/Explorer 实机待测 |
| 用户是在远程服务器上开 DSH 怎么办？ | 先拒绝远程请求，不假装有完整登录继承 | Node HTTP 安全边界测试；远程模式未实现 |
| 文件拖到侧栏会不会误建工作区？ | 只接受一个根文件夹；显示错误并禁用确认 | 实际 UI 发现并修复过按钮未禁用问题 |
| 拖入项目会不会偷偷把密钥发出去？ | 默认跳过常见敏感文件名；用户可明确纳入 | 检查 .env 排除/提示；不是内容秘密扫描器 |
| node_modules 是否白白扫完才跳过？ | 遇到排除目录就不进入子树 | 枚举调用测试确认没有递归读取 |
| 文件夹超过 100 项会不会漏？ | 循环读取到 readEntries 返回空 | 101 项分批目录枚举回归 |
| 空文件夹还在不在？ | drop 条目接口可见的空目录保留 | 真目录落盘断言；picker 无法保证空目录 |
| 为什么不一拖入就上传？ | 对话 copy-on-send，降低误拖后主机残留 | 确认之前实际主机目录没有文件副本 |
| 向侧栏导入还要等发消息吗？ | 不等；工作区导入是独立事务与专用 scope | 没有活动会话也可导入的 store 测试 |
| 上传完、消息失败，会不会丢文件或显示假成功？ | “已保存”和“已发送”分开；保存回执可复用 | 本次验证保存；真实 DSH 消息恢复仍是门槛 |
| 断网重试会不会复制两份？ | 复用批次；完成文件按收据跳过 | 故障注入、真实文件 SHA-256 与幂等提交 |
| 中断到一半能从字节偏移续传吗？ | 不能；未完成单文件从头重传，已完成文件不重传 | 文案不使用字节级断点续传承诺 |
| 取消能保证磁盘从未出现任何字节吗？ | 不能；取消中止后清暂存。不得删已提交副本 | Abort、取消与清理边界测试 |
| 多个文件同名、大小写或 Unicode 不同怎么办？ | 拒绝有歧义的路径，不静默覆盖 | NFC/casefold、父文件冲突、遍历路径测试 |
| 插件卸载会不会破坏原程序？ | 不改核心 bundle；监听器/slot/路由按生命周期释放 | 适配器 dispose 测试；真实卸载仍待实测 |
| 为删除一张卡片重写整个输入框行不行？ | 不行。使用带 revision 的局部公开操作 | 外部技能引用与本插件引用并存回归 |
| 官方没有对应局部接口会不会静默降级？ | 不做破坏性 fallback，显示失败保留其他内容 | 不匹配接口测试 |
| 图片预览就等于模型能看图吗？ | 不等于。纯图片原生交接；混合路径附件明确标注 | 事件放行测试，不冒充实际视觉模型验收 |
| 所有格式都要内嵌预览吗？ | 不要。栅格图片/有界文本；其他格式可下载 | 文本转义、图片解码测试；无 Office/PDF 解析器 |
| 预览 SVG、HTML 会不会执行代码？ | 按文本显示，不作为页面或 iframe 加载 | 代码转义与预览 MIME 边界测试 |
| 需要多少“高级动画”才能显得好？ | 很少。短反馈、不挡操作、尊重减少动态效果 | 暗色/390px/键盘测试；通知已改到非发送区 |
| 刷新后未发送附件恢复吗？ | 本版不恢复浏览器 File，避免伪造已恢复状态 | README 明示；已提交历史来自真实 manifest |
| 已发送文件可以自动清理吗？ | 不自动删；暂存 TTL，已提交只显式清理 | 跨会话/原目录/v1 保留断言 |
| 可否现在声称完整从原仓库升级成功？ | 不能。完整克隆失败，host 原文件未取得 | PROVENANCE 记录；覆盖脚本可逆，不伪造 git diff |
| 能否现在打稳定版并宣称兼容所有 DSH？ | 不能。核心与夹具通过不等于原生认证 | 发布门禁实际失败，等待真实证据 |

## 留在下一阶段，而不是假装本版已完成

真实 DSH 的发送/失败恢复、安装卸载和原生目录拖拽是**发布前**工作，不是可有可无的后续功能。远程鉴权、多浏览器实机、原生历史卡片、自适应新版官方附件 API 和刷新恢复则是进一步范围，不能在候选版宣传页打勾。
