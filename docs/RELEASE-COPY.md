# Better Attach 0.3.0-rc.5

Better Attach adds folder review, file previews, copy-on-send and original-path conversation attachments to DeepSeek Harness. Sidebar drops register the original host directory as a workspace. Real DSH integration, browser workflows and model responses have been verified; OS-native cross-window drag acceptance remains pending. See [verification](ACCEPTANCE.md).

Better Attach 为 DSH 提供文件夹检查、文件预览、发送时复制及原路径对话附件。侧栏拖放将主机原目录添加为工作区。真实 DSH 联调、浏览器流程和模型回复已验证；操作系统原生跨窗口拖放仍待确认。详见[验收记录](ACCEPTANCE.md)。
